## Changes

- **Draft preflight:** increases output headroom from 3,072 to 6,144 tokens and uses a compact provider response. A single rule enum replaces three repeated booleans; shorter exact source clauses and brief labels reduce repetition. The server expands the result back to the existing signed/API contract, preserving mandatory, optional, conditional, critical and missing semantics. Present mandatory documents are still listed and rechecked. Partial output remains a failure, never an approvable draft. Future output-limit logs include bounded token/thinking counts and model version, without output text.
- **Profile coverage:** verification explicitly looks for facts omitted from the initial extraction, including bilingual content. Recovery requires a field-specific source quote. Correction starts from the full candidate profile and must explain removals. If correction omits a populated extracted field without a finding, the app retains it with an explicit **unconfirmed draft** review check. A finding against that field, or an unknown/general finding scope, prevents automatic retention. All verification findings remain visible, and every still-missing profile field receives a review check. The app does not fill from the old saved profile or auto-approve recovered facts.
- **Entity types and states:** one shared fixed type list normalizes case, spacing and common aliases. `Incorporated Association` becomes `Incorporated association`, without a duplicate option. Unknown source types map to Other with a review note; blank types stay blank. Full Australian state names map to their normal abbreviations.
- **Stable source links:** resolves Google's known grounding redirect endpoint before saving a primary source URL. It uses manual redirects, a bounded three-second lookup, and never fetches a returned funder destination. Unsafe/private/non-HTTPS targets are rejected. The stable URL is primary and the original citation remains in provenance. Matching old redirect records can be repaired while preserving guidelines, status and round dates; unresolved citations are skipped with a clear message instead of saved as temporary links.
- **Spreadsheet evidence in drafting:** the application editor now offers an explicit supporting-document selection, initially empty, limited to eight documents/15 MiB. Choices persist with the application. The same selected originals reach both preflight and generation under the existing source/version receipt checks. Prompts require sheet/cell citations, treat cached formula results as unverified saved values, and keep missing/error results as missing information rather than recalculating or inventing them.

No migration, new environment variable, dependency update or provider-key change is required. Raising the output ceiling can increase provider usage. Files are only included in a draft when the user selects them; merely uploading one does not send it for drafting.
