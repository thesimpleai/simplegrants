# Simple Grants brand assets

`simple-ai-mark.png` is the original 833 × 914 image embedded as image object 27
in the supplied `Easy_Compliance_Brand_Guidelines_v1 (1).pdf` (v1.0, May 2026).
Its embedded soft mask (object 29) is restored as alpha. The artwork has not been
redrawn, recoloured, distorted, or generated. It is used for the product logo and
favicon. The separately named PNG master attachments were not available here.

The palette and recommended fonts follow pages 5–6 of that guide. The live
easycompliance.org stylesheet could not be inspected because it returned HTTP
403, so typography follows the guide's recommended system.

The self-hosted variable font subsets come from the Google Fonts repository:

- Hanken Grotesk: `google/fonts/ofl/hankengrotesk`
- Plus Jakarta Sans: `google/fonts/ofl/plusjakartasans`
- JetBrains Mono: `google/fonts/ofl/jetbrainsmono`

Each font's SIL Open Font License is included in `fonts/`. Subsets retain Latin,
extended Latin, punctuation, currency symbols and arrows. No third-party font
request is made when using the application.
